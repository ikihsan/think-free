 README.md 
 

 
 
 
 
 
 
 cpp-linter runs clang-format and clang-tidy on C and C++ code: on every pull request,
before every commit and on your laptop, at the same LLVM version. 
 Website ·
 Get started ·
 Showcase ·
 Discussions ·
 Sponsor 
 Pick where the checks run 
 
 
 
 Where 
 Project 
 Start with 
 
 
 
 
 On every pull request 
 cpp-linter-action 
 uses: cpp-linter/cpp-linter-action@v2 
 
 
 Before every commit 
 cpp-linter-hooks 
 args: [--style=file, --version=21] 
 
 
 Locally or in other CI 
 cpp-linter 
 pip install cpp-linter 
 
 
 Just the clang tools 
 clang-tools 
 pip install clang-tools 
 
 
 
 The clang tools also come as static binaries 
for Linux, macOS and Windows, a Homebrew tap for macOS,
an asdf plugin and
 Docker images . 
 Maintained by two volunteers, @shenxianpeng and
 @2bndy5 . Sponsorship goes to the project through
 Open Collective , where all income and expenses are public.
