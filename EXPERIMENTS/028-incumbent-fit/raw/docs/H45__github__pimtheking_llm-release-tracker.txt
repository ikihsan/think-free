## 🔍 Hoe het werkt

### 1. Zoekstrategie
Het systeem gebruikt slimme zoekopdrachten zoals:
- "OpenAI next model after GPT-4o"
- "Google new LLM rumors"
- "Meta Llama 4 release"

### 2. Patroonherkenning
Zoekt naar patronen in modelnamen:
- `GPT-5`, `Llama-4`, `Claude-4`
- `Gemini-Ultra`, `Palm-2`
- Nieuwe naamgeving conventies

### 3. Releasedatum Zoeken
Voor elk gevonden model zoekt het systeem naar de verwachte releasedatum:
- "GPT-5 expected release date"
- Gebruikt `dateparser` voor intelligente datum-extractie
- Ondersteunt formaten zoals "Q4 2025", "november 2025", "eind 2025"
- Filtert alleen toekomstige datums

### 4. Analyse & Opslag
- **Sentiment analyse**: Positieve/negatieve berichten
- **Confidence scoring**: Betrouwbaarheid van voorspellingen
- **Automatische opslag**: Alle voorspellingen in `data.json`
- **Duplicaat detectie**: Bestaande voorspellingen worden bijgewerkt

## 📈 Resultaten Interpretatie

### Confidence Score
- **0.0-0.3**: Lage betrouwbaarheid
- **0.3-0.6**: Gemiddelde betrouwbaarheid  
- **0.6-1.0**: Hoge betrouwbaarheid

### Evidence Count
Aantal keer dat een model genoemd wordt in zoekresultaten.

### Releasedatum
Verwachte releasedatum (gebaseerd op web geruchten).

## 🤖 Automatisering

### GitHub Actions Workflow
Het systeem draait automatisch elke dag om 06:00 Nederlandse tijd:

1. **Data Collection**: Zoekt naar nieuwe geruchten
2. **Analysis**: Analyseert en voorspelt nieuwe modellen
3. **Update**: Werkt `data.json` bij
4. **Deploy**: Publiceert naar GitHub Pages

### Handmatige Updates
Je kunt ook handmatig updates triggeren:
1. Ga naar **Actions** tab in GitHub
2. Selecteer **"Update LLM Data"** workflow
3. Klik **"Run workflow"**
