# E105 — Software Stack Exchange view_count + unserved-open measurement

**Status:** Experiment complete.

**Date:** 2026-10-11

**Question:** Can the view_count arrival instrument and unserved-open-like fraction be measured on software-focused Stack Exchange sites (Stack Overflow, Server Fault, Super User)? This is a fresh observation in a new domain per D083.

**Expected outcome:**
- If G1-G3 pass: The view-count principle generalizes to software SE, and the unserved fraction is measurable — this would open a new potential candidate domain.
- If G1 passes but G3 fails: The principle generalizes but the unserved fraction is too high for candidate generation (population uniformly served or over-whelmed by unmet needs).
- If G1 fails: The view_count instrument does not generalize to software SE.

**Result:** G1 PASS, G2 PASS, G3 FAIL. The view-count principle generalizes to software SE (100% view_count coverage, 50% need prevalence), but the unserved-open-like fraction is 86.7% (13/15 need topics unserved), far above the 50% gate threshold. The software-SE route is closed for candidate generation.

**Next steps per D083:** Per the mission's fresh-observation protocol, this experiment tests a genuinely new domain not previously covered. The result adds to the mission's boundary map of the view-count principle.
