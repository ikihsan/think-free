- [Akshat Parashar] You may want to do this just for the workspace, since doing this in vsCode settings JSON globally will effect every project containing .css file, so if you're not using tailwind css in all projects, it'll not be desireable. To change it just for current project go to .vscode(create in project root if required)>settings.json(create in project root if required). Add the above mentioned solution.
- [rozsazoltan] @AkshatParashar Yes, that can work too, though I do it the other way around. By default (User Setting), Tailwind is enabled everywhere ( `USERPATH/settings.json` > `"files.associations": {"*.css": "tailwindcss"}` ), and if I happen not to use it somewhere, I disable it in that specific workspace ( `.vsocde/settings.json` > `"files.associations": {"*.css": "css"}` ). Each person chooses according to their preference, either in the user `settings.json` (CTRL + SHIFT + P -- "Open User Settings") or the workspace `.vscode/settings.json` .
