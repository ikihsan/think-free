PROPOSED ANSWER:
The node binary downloaded fine; only the npm step failed, because nvm-windows extracts npm into a temporary folder and something deletes or blocks it before it is read. Common causes: Defender or another AV quarantines the temp files, the %TEMP% path is inaccessible or too long, or you are not elevated. Run nvm install from an elevated prompt, add the temp directory and NVM_HOME to Defender exclusions, then delete leftover nvm-install-* and nvm-npm-* folders and retry. If it still fails, bypass the npm step: download node-v14.17.3-win-x64.zip yourself, extract it to %NVM_HOME%\v14.17.3, and run nvm use 14.17.3. For old Node versions generally, nvm for Linux/WSL, fnm or n avoid the problem because they unpack official archives.
