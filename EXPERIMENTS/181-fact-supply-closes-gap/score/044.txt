PROPOSED ANSWER:
The warning is not about the libraries any more and aligning more .so files will not clear it. It is an artefact-level warning, and what decides it is which artefact you are inspecting: it appears only in the apk, while an app bundle built from the same project is clean - people who switched to uploading the bundle saw it disappear. So verify the bundle as well and ship the .aab. If you want the apk clean too, check how that apk was produced: zipalign must have been run with -P 16 rather than the default 4, and a stale or differently-produced apk keeps the warning even with aligned libraries. Re-run alignment on the exact apk you are analysing, then confirm with zipalign -c -P 16 and check_elf_alignment.sh on the extracted libs.
