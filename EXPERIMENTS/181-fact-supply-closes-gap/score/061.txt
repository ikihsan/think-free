The uv installation detail is from another thread and does not bear on this. The reason npx cannot find the executable is that the Tailwind CLI is no longer exposed by the tailwindcss package in recent versions - it is its own package now, and the JavaScript config file has gone with it. So install and run the CLI as npx @tailwindcss/cli init, and configure in CSS rather than in tailwind.config.js: @import "tailwindcss", @theme for tokens, @utility for extensions, @source for files to scan. Where the v4 docs and the upgrade guide disagree, the upgrade guide is right, because the reference page was still being corrected shortly after release.
