PROPOSED ANSWER:
The Expo beta detail from another thread does not apply here. What is happening in iOS 26 is that the glass bar applies its own tint to custom views, overriding what you set: tintColor inheritance for a custom view is documented as unreliable and 26 makes it more pronounced, so setting it again changes nothing. Set colours directly instead. For a UIButton use UIButton.Configuration - set the image with withTintColor and renderingMode .alwaysTemplate, and put selectedBackgroundTintColor, setTitleColor and backgroundColor on the configuration rather than the view. For a UISegmentedControl call setSelectedSegmentTintColor; for a UISwitch set onTintColor. Do not rely on inherited tint and do not use UIBarButtonItem(tintColor:) expecting it to reach a custom view.

ACCEPTED ANSWER ON THE SITE:
It is a really frustrating situation and here is what has worked for me: 
 
 `baseForegroundColor` and `imageColorTransformer` works only if `UIButton.Configuration` is `.clearGlass` or `.prominentClearGlass` 
 
 
 THIS WORKS FOR ALL STYLES as stated in mhammad's answer 
 `withTintColor` and `withRenderingMode(.alwaysOriginal)` 
 `config.image = UIImage(systemName: "star")?.withTintColor(.magenta) .withRenderingMode(.alwaysOriginal)
` 
 
 
 THIS ALSO WORKS FOR ALL STYLES take a snapshot of your custom view (UIGraphicsImageRenderer) and use `UIBarButtonItem(image: snapshot-of-custom-view)` or set `self.image = snapshot-of-custom-view` property if you are using custom class with a `tintColor` for `UIBarButtonItem` . 
 `final class BarButtonItem: UIBarButtonItem {
// ...
 init() {
 self.image = UIGraphicsImageRenderer(size: button.intrinsicContentSize).image { [weak button] c in
 button?.layer.render(in: c.cgContext)
 }
 tintColor = .systemOrange
 }
}
`

import UIKit

@MainActor
func makeButton(_ config: UIButton.Configuration, title: String) -> UIButton {
 var config = config
 config.title = title
 config.contentInsets = .init(top: 8, leading: 8, bottom: 8, trailing: 8)
 config.imagePlacement = .top
 config.cornerStyle = .capsule
 config.baseForegroundColor = .green
 config.imageColorTransformer = .init({ _ in
 UIColor.systemPink
 })
 config.titleTextAttributesTransformer = .init({ c in
 var c = c
 c.foregroundColor = .blue
 return c
 })
 config.baseBackgroundColor = .systemYellow
 config.image = .init(systemName: "star", withConfiguration: UIImage.SymbolConfiguration(scale: .small))
// Solution 2. Using image renderingMode and tint

 return v
}
