PROPOSED ANSWER:
You installed v4, and that is the entire answer. In v4 the JavaScript configuration file has been removed - settings live in CSS via @import "tailwindcss" plus @theme - and the CLI moved into its own package, so npx tailwindcss init -p cannot resolve an executable. So run npx @tailwindcss/cli init if you want the scaffold, and move your config into the stylesheet: @theme for tokens, @utility for extensions, @custom-variant for variants, @source to mark files to scan. Two further notes from this thread: the v4 documentation was still inaccurate shortly after release and the command on the reference page is wrong, so follow the upgrade guide when they disagree; and with Vite there is a dedicated install path worth reading instead.
