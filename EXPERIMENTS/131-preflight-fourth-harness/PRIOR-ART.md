# Prior art — three checks that gate whether an evaluation harness may report a rate

The prior art for the three checks (C1 concordance, C2 alternate-form FP, C3 control arm)
is documented in the main preflight experiment:
[`EXPERIMENTS/124-eval-harness-preflight/PRIOR-ART.md`](../124-eval-harness-preflight/PRIOR-ART.md).
