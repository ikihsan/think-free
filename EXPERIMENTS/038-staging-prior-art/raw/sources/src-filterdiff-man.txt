<section class="Sh">
<h1 class="Sh" id="NAME">NAME<a class="anchor" href="#NAME">¶</a></h1>
<p class="Pp">filterdiff - extract or exclude diffs from a diff file</p>
</section>
<section class="Sh">
<h1 class="Sh" id="SYNOPSIS">SYNOPSIS<a class="anchor" href="#SYNOPSIS">¶</a></h1>
<p class="Pp HP"><b>filterdiff</b> [[-i <i>PATTERN</i>] |
    [--include=<i>PATTERN</i>]] [[-I <i>FILE</i>] |
    [--include-from-file=<i>FILE</i>]] [[-p <i>n</i>] |
    [--strip-match=<i>n</i>]] [--strip=<i>n</i>] [--addprefix=<i>PREFIX</i>]
    [--addoldprefix=<i>PREFIX</i>] [--addnewprefix=<i>PREFIX</i>]
    [[-x <i>PATTERN</i>] | [--exclude=<i>PATTERN</i>]]
    [[-X <i>FILE</i>] | [--exclude-from-file=<i>FILE</i>]] [[-v] |
    [--verbose]] [--clean] [[-z] | [--decompress]] [[-# <i>RANGE</i>] |
    [--hunks=<i>RANGE</i>]] [--lines=<i>RANGE</i>] [[-F<i>RANGE</i>] |
    [--files=<i>RANGE</i>]] [--annotate] [--format=<i>FORMAT</i>]
    [--as-numbered-lines=<i>WHEN</i>] [--remove-timestamps] [<i>file</i>...]</p>
<p class="Pp HP"><b>filterdiff</b> {[--help] | [--version] | [--list] |
    [--grep ...]}</p>
</section>
<section class="Sh">
<h1 class="Sh" id="DESCRIPTION">DESCRIPTION<a class="anchor" href="#DESCRIPTION">¶</a></h1>
<p class="Pp">You can use filterdiff to obtain a patch that applies to files
    matching the shell wildcard <i>PATTERN</i> from a larger collection of
    patches. For example, to see the patches in patch-2.4.3.gz that apply to all
    files called lp.c:</p>
<p class="Pp"></p>
<div class="Bd-indent">
<pre>filterdiff -z -i &#39;*/lp.c&#39; patch-2.4.3.gz</pre>
</div>
<p class="Pp">If neither <b>-i</b> nor <b>-x</b> options are given, <b>-i
    &#39;*&#39;</b> is assumed. This way <b>filterdiff</b> can be used to clean up an
    existing diff file, removing redundant lines from the beginning (eg. the
    text from the mail body) or between the chunks (eg. in CVS diffs). To
    extract pure patch data, use a command like this:</p>
<p class="Pp"></p>
<div class="Bd-indent">
<pre>filterdiff message-with-diff-in-the-body &gt; patch</pre>
</div>
<p class="Pp">Note that the interpretation of the shell wildcard pattern does
    not count slash characters or periods as special (in other words, no flags
    are given to <b>fnmatch</b>). This is so that
    “*/basename”-type patterns can be given without limiting the
    number of pathname components.</p>
<p class="Pp">You can use both unified and context format diffs with this
    program.</p>
</section>
<section class="Sh">
<h1 class="Sh" id="OPTIONS">OPTIONS<a class="anchor" href="#OPTIONS">¶</a></h1>
<p class="Pp"><b>-i</b> <i>PATTERN</i>,
  <b>--include=</b><b></b><i>PATTERN</i></p>
<div class="Bd-indent">Include only files matching <i>PATTERN</i>. All other
  lines in the input are suppressed.</div>
<p class="Pp"><b>-I</b> <i>FILE</i>,
    <b>--include-from-file=</b><b></b><i>FILE</i></p>
<div class="Bd-indent">Include only files matching any pattern listed in
  <i>FILE</i>, one pattern per line. All other lines in the input are
  suppressed.</div>
<p class="Pp"><b>-x</b> <i>PATTERN</i>,
  <b>--exclude=</b><b></b><i>PATTERN</i></p>
<div class="Bd-indent">Exclude files matching <i>PATTERN</i>. All other lines in
  the input are displayed.</div>
<p class="Pp"><b>-X</b> <i>FILE</i>,
    <b>--exclude-from-file=</b><b></b><i>FILE</i></p>
<div class="Bd-indent">Exclude files matching any pattern listed in <i>FILE</i>,
  one pattern per line. All other lines in the input are displayed.</div>
<p class="Pp"><b>-p</b> <i>n</i>, <b>--strip-match=</b><b></b><i>n</i></p>
<div class="Bd-indent">When matching, ignore the first <i>n</i> components of
  the pathname.</div>
<p class="Pp"><b>-#</b> <i>RANGE</i>, <b>--hunks</b>=<i>RANGE</i></p>
<div class="Bd-indent">Only include hunks within the specified <i>RANGE</i>.
  Hunks are numbered from 1, and the range is a comma-separated list of numbers
  or “first-last” spans, optionally preceded by a modifier &#39;x&#39;
  which inverts the entire range; either the first or the last in the span may
  be omitted to indicate no limit in that direction.</div>
<p class="Pp"><b>--lines</b>=<i>RANGE</i></p>
<div class="Bd-indent">Only include hunks that contain lines from the original
  file that lie within the specified <i>RANGE</i>. Lines are numbered from 1,
  and the range is a comma-separated list of numbers or
  “first-last” spans, optionally preceded by a modifier &#39;x&#39; which
  inverts the entire range; either the first or the last in the span may be
  omitted to indicate no limit in that direction.</div>
<p class="Pp"><b>-F</b>=<i>RANGE</i>, <b>--files</b>=<i>RANGE</i></p>
<div class="Bd-indent">Only include files indicated by the specified
  <i>RANGE</i>. Files are numbered from 1 in the order they appear in the patch
  input, and the range is a comma-separated list of numbers or
  “first-last” spans, optionally preceded by a modifier &#39;x&#39; which
  inverts the entire range; either the first or the last in the span may be
  omitted to indicate no limit in that direction.</div>
<p class="Pp"><b>--annotate</b></p>
<div class="Bd-indent">Annotate each hunk with the filename and hunk
  number.</div>
<p class="Pp"><b>--format</b>=unified|context</p>
<div class="Bd-indent">Use specified output format.</div>
<p class="Pp"><b>--strip</b>=<i>n</i></p>
<div class="Bd-indent">Remove the first <i>n</i> components of pathnames in the
  output.</div>
<p class="Pp"><b>--addprefix</b>=<i>PREFIX</i></p>
<div class="Bd-indent">Prefix pathnames in the output by <i>PREFIX</i>. This
  will override any individual settings specified with the <b>--addoldprefix</b>
  or <b>--addnewprefix</b> options.</div>
<p class="Pp"><b>--addoldprefix</b>=<i>PREFIX</i></p>
<div class="Bd-indent">Prefix pathnames for old or original files in the output
  by <i>PREFIX</i>.</div>
<p class="Pp"><b>--addnewprefix</b>=<i>PREFIX</i></p>
<div class="Bd-indent">Prefix pathnames for updated or new files in the output
  by <i>PREFIX</i>.</div>
<p class="Pp"><b>--as-numbered-lines</b>=before|after</p>
<div class="Bd-indent">Instead of a patch fragment, display the lines of the
  selected hunks with the line number of the file before (or after) the patch is
  applied, followed by a TAB character and a colon, at the beginning of each
  line. Each hunk except the first will have a line consisting of
  “...” before it.</div>
<p class="Pp"><b>--remove-timestamps</b></p>
<div class="Bd-indent">Do not include file timestamps in the output.</div>
<p class="Pp"><b>-v</b>, <b>--verbose</b></p>
<div class="Bd-indent">Always show non-diff lines in the output. By default,
  non-diff lines are only shown when excluding a filename pattern.</div>
<p class="Pp"><b>--clean</b></p>
<div class="Bd-indent">Always remove all non-diff lines from the output. Even
  when excluding a filename pattern.</div>
<p class="Pp"><b>-z</b>, <b>--decompress</b></p>
<div class="Bd-indent">Decompress files with extensions .gz and .bz2.</div>
<p class="Pp"><b>--help</b></p>
<div class="Bd-indent">Display a short usage message.</div>
<p class="Pp"><b>--version</b></p>
<div class="Bd-indent">Display the version number of filterdiff.</div>
<p class="Pp"><b>--list</b></p>
<div class="Bd-indent">Behave like <a href="/bookworm/patchutils/lsdiff.1.en.html">lsdiff(1)</a> instead.</div>
<p class="Pp"><b>--grep</b></p>
<div class="Bd-indent">Behave like <a href="/bookworm/patchutils/grepdiff.1.en.html">grepdiff(1)</a> instead.</div>
</section>
<section class="Sh">
<h1 class="Sh" id="EXAMPLES">EXAMPLES<a class="anchor" href="#EXAMPLES">¶</a></h1>
<p class="Pp">To see all patch hunks that affect the first five lines of a C
    file:</p>
<p class="Pp"></p>
<div class="Bd-indent">
<pre>filterdiff -i &#39;*.c&#39; --lines=-5 &lt; patch</pre>
</div>
<p class="Pp">To see the first hunk of each file patch, use:</p>
<p class="Pp"></p>
<div class="Bd-indent">
<pre>filterdiff -#1 patchfile</pre>
</div>
<p class="Pp">To see patches modifying a ChangeLog file in a subdirectory,
  use:</p>
<p class="Pp"></p>
<div class="Bd-indent">
<pre>filterdiff -p1 Changelog</pre>
</div>
<p class="Pp">To see the complete patches for each patch that modifies line 1 of
    the original file, use:</p>
<p class="Pp"></p>
<div class="Bd-indent">
<pre>filterdiff --lines=1 patchfile | lsdiff | \
<br/>
  xargs -rn1 filterdiff patchfile -i</pre>
</div>
<p class="Pp">To see all but the first hunk of a particular patch, you might
    use:</p>
<p class="Pp"></p>
<div class="Bd-indent">
<pre>filterdiff -p1 -i file.c -#2- foo-patch</pre>
</div>
<p class="Pp">If you have a very specific list of hunks in a patch that you want
    to see, list them:</p>
<p class="Pp"></p>
<div class="Bd-indent">
<pre>filterdiff -#1,2,5-8,10,12,27-</pre>
</div>
<p class="Pp">To see the lines of the files that would be patched as they will
    appear after the patch is applied, use:</p>
<p class="Pp"></p>
<div class="Bd-indent">
<pre>filterdiff --as-numbered-lines=after patch.file</pre>
</div>
<p class="Pp">You can see the same context before the patch is applied with:</p>
<p class="Pp"></p>
<div class="Bd-indent">
<pre>filterdiff --as-numbered-lines=before
patch.file</pre>
</div>
<p class="Pp">Filterdiff can also be used to convert between unified and context
    format diffs:</p>
<p class="Pp"></p>
<div class="Bd-indent">
<pre>filterdiff -v --format=unified context.diff</pre>
</div>
