=== TITLE ===
Bug in GCC when using string literal as const char(&amp;)[N] through functor in templated 
function

 template<typename T> requires (const_lit<T>::Count > 0)

=== KEY ANSWER ===
This is an old gcc bug where gcc decays the string literal to const char* too early when p
assed to a function pointer. As mentioned in the bug report, the minimial example can be r
educed to: 
 
 struct SL{
 template <int N>
 SL(const char (&Str)[N]) {}
};

int foo(SL x) {
 return 2;
}

int main() {
 int (*f)(SL) = &foo;
 foo("asd"); // works fine
 f("asd"); // error could not convert '(const char*) to SL
}
