Sentry errors &quot;Can&#39;t find variable: gmo&quot;, &quot;invalid or unexpected token&
quot; due to Google ads snippet in index.html of our react app

=== QUESTION ===
We very recently set up Google ads for our react app. Our React app is a 7-8 year old app 
originally built with create-react-app. Now, in Sentry we are getting these two errors, bo
th with steady volume over the last week since launching Google ads: 
 
 
 Here is our apps index.html showing the Google tag (with a fake AW-number): 
 <!-- For Google Ads to be run on Search (not on the website) -->
 <!-- Google tag (gtag.js) -->
 <script async src="https://www.googletagmanager.com/gtag/js?id=AW-123456789">
 </script>
 <script>
 window.dataLayer = window.dataLayer || [];
 function gtag(){dataLayer.push(arguments);}
 gtag('js', new Date());

 gtag('config', 'AW-123456789');
 </script>
 <!-- End -->
 
 LLM suggested to add window.gmo = window.gmo || {}; as the first line in the script (just
 above window.dataLayer = window.dataLayer || []; ) to resolve the "cant find variable: gm
o" error, but this isn't something mentioned / included in https://developers.google.com/t
ag-platform/gtagjs . It thinks gmo = Google Marketing Object. 
 LLM also suggested to add handling of query/search parameters into our App.js file to res
olve the "invalid or unexpected token" error. Currently, our app uses nearly zero query/se
arch params other than this google tag, rather we use route params for all of our routing.

=== KEY ANSWER ===
I think the best approach here would be to use the ignoreErrors option https://docs.sentry
.io/platforms/javascript/configuration/filtering/ 
 Sentry.init({
 ignoreErrors: [
 "Can't find variable: gmo"
 ],
});
