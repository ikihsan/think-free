=== TITLE ===
Create project with specific (downgraded) Python version

=== QUESTION ===
At work, I am running 3.9.21. At home, I am running Python 3.13.2 on Linux, but also use u
v install Python 3.9.21 to be in sync with work. 
 In my home machine, I created a new project: 
 uv init --package --python "python==3.9.21" sandbox
cd sandbox
uv sync
 
 At this time, I got the following error: 
 Using CPython 3.13.2
error: The requested interpreter resolved to Python 3.13.2, which is incompatible with the
 project's Python requirement: `==3.9.21`
 
 How can I create a project with this specific version (3.9.21) of Python?

=== KEY ANSWER ===
I tried your steps in my macbook and they worked fine without any error. 
 Your error sounds as if uv was installed via pip install uv under Python 3.13.2.
Could that be? 
 This is why Astral (who programmed uv ) warns not to install uv simply with pip install u
v . Because then, the uv gets dependent on the particular Python version. But the point of
 uv is that it should be in the level on top of the Python versions and manage them. 
 Your uv seems to be installed under Python 3.13.2, thus fixed to it - which is suboptimal
.
And it has performance penalties - you are not using uv (Rust's) actual speed - but uv ins
ide pip . 
 The solution in this case would be: 
 
 uninstall pip uninstall uv 
 globally install uv 
 
 # macos and linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# windows
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
 
 or just look in https://docs.astral.sh/uv/getting-started/installation/#__tabbed_1_2 
 And with the global uv your steps should work without problems.
