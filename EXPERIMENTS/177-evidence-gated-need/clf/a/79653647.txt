=== KEY ANSWER ===
Try adding phantomver = NULL to rsDriver() call to explicitly exclude PhantomJS, 
 remote_driver <- rsDriver(..., phantomver = NULL)
 

 phantomver = NULL 
 rsDriver() 
 remote_driver <- rsDriver(..., phantomver = NULL)
