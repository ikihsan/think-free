=== LEFT ===
This is an iOS 26 behaviour change: bar items now live in the new glass bar environment, a
nd the bar applies its own tint to custom views, overriding what you set on them. tintColo
r inheritance for a custom view is documented as unreliable, and 26 makes that more pronou
nced. Stop relying on inherited tint and set colors directly on the content: build the but
ton with UIButton.Configuration and set baseForegroundColor, or use a UIImage with withTin
tColor and renderingMode .alwaysTemplate, set the segmented control's selectedSegmentTintC
olor and its title text attribute foreground color, and use UISwitch's stateful setter set
ThumbTintColor(_:for: .off) if you need the thumb. tintColor on UIBarButtonItem(customView
:) or on the navigation bar is not a supported way to color a custom view.

=== RIGHT ===
It is a really frustrating situation and here is what has worked for me: 
 
 baseForegroundColor and imageColorTransformer works only if UIButton.Configuration is .cl
earGlass or .prominentClearGlass 
 
 
 THIS WORKS FOR ALL STYLES as stated in mhammad's answer 
 withTintColor and withRenderingMode(.alwaysOriginal) 
 config.image = UIImage(systemName: "star")?.withTintColor(.magenta) .withRenderingMode(.a
lwaysOriginal)
 
 
 
 THIS ALSO WORKS FOR ALL STYLES take a snapshot of your custom view (UIGraphicsImageRender
er) and use UIBarButtonItem(image: snapshot-of-custom-view) or set self.image = snapshot-o
f-custom-view property if you are using custom class with a tintColor for UIBarButtonItem 
. 
 final class BarButtonItem: UIBarButtonItem {
// ...
 init() {
 self.image = UIGraphicsImageRenderer(size: button.intrinsicContentSize).image { [weak but
ton] c in
 button?.layer.render(in: c.cgContext)
 }
 tintColor = .systemOrange
 }
}

 //: A UIKit based Playground for presenting user interface

import UIKit
import PlaygroundSupport

@MainActor
func makeButton(_ config: UIButton.Configuration, title: String) -> UIButton {
 var config = config
 config.title = title
 config.contentInsets = .init(top: 8, leading: 8, bottom: 8, trailing: 8)
 config.imagePlacement = .top
 config.cornerStyle = .capsule
 config.baseForegroundColor = .green
 config.imageColorTransformer = .init({ _ in
 UIColor.systemPink
 })
 config.titleTextAttributesTransformer = .init({ c in
 var c = c
 c.foregroundColor = .blue
 return c
 })
 config.baseBackgroundColor = .systemYellow
 config.image = .init(systemName: "star", withConfiguration: UIImage.SymbolConfiguration(s
cale: .small))
// Solution 2. Using image renderingMode and tint
// config.image = .init(systemName: "star", withConfiguration: UIImage.SymbolConfiguration
(scale: .small))?.withTintColor(.magenta) .withRenderingMode(.alwaysOriginal)
 let v = UIButton(configuration: config)
 v.tintColor = .blue
 return v
}
