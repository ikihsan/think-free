=== LEFT ===
Turn it off in Tools: Options. For the suggestion list, open Tools -> Options -> Text Edit
or -> IntelliSense and uncheck Enable IntelliSense (or, for C++, set Enable IntelliSense t
o Disabled under Text Editor -> C/C++ -> Advanced). Copilot has its own page, Tools -> Opt
ions -> GitHub Copilot, with checkboxes to turn off completions and chat; otherwise uninst
all the GitHub Copilot and GitHub Copilot Chat extensions from Extensions -> Installed and
 restart Visual Studio. To disable Copilot fully for the machine, turn off both the Option
s checkboxes and remove the extensions, since Copilot also contributes the whole-document 
completion you are seeing.
